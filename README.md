#Car Accident Detector
An AI -based car accident detection system using YOLO and OpenCV

#Technologies Used
- python
- YOLO
- OpenCV
- Computer Vision

##Features
- Vehicles detection using YOLO
- Accident detection
- Alert sound notificationj
- GPS and time loggging
- Accident data storage

  ## Project Purpose
  This project aims to detect possible road accidents using computer vision and provide alerts for quick response.

  ## How to Run
  1. Install required libraries
  2. Run the python file
  3. Start camera detection
